# Topic pool

Students vote on the next topic from 3 options in this list.

A topic can go on a ballot only when:
- its prerequisites are built or are being built;
- its facts have sources;
- the game part can be built in about a week.

Sources are the parent spec's list (`docs/superpowers/specs/2026-09-30-worm-simulator-design.md`,
section 5). Re-check each source before it's used on slides.

Status values: `pool` (can go on a ballot) · `needs source` · `blocked` (prerequisite missing) ·
`on ballot` · `chosen (VN)` · `done (VN)`.
